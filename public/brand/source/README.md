## Official palette (Option A)

| Token                           | Marketing name | Hex       | Role                                    |
| ------------------------------- | -------------- | --------- | --------------------------------------- |
| Aero Blue                       | Horizon Blue   | `#2E7DAA` | Primary brand / CTAs / AVIATOR wordmark |
| Altitude Orange / Success Amber | Sun Gold       | `#DD9B30` | Accent / PASS wordmark / highlights     |
| Academic Grey                   | Academic Grey  | `#7C7B80` | Secondary / muted UI / book mark        |

## Typography

| Role     | Brand font      | Web substitute               |
| -------- | --------------- | ---------------------------- |
| Headings | Stimulatio Flat | Space Grotesk                |
| Body     | IBM Plex Sans   | IBM Plex Sans (Google Fonts) |

Load licensed Stimulatio Flat under `public/fonts/` when available and set `brandingConfig.pending.officialTypography = false`.
