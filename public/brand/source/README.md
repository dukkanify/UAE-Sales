# Brand source assets

Official AviatorPass brand guidelines for audit and regeneration of digital assets.

## Files

| File                               | Purpose                              |
| ---------------------------------- | ------------------------------------ |
| `AVIATORPASS_Brand_Guidelines.pdf` | Official brand book (current upload) |
| `guidelines-01.png` …              | Cover / TOC / palette page renders   |
| `guidelines-logo-07.png` …         | Logo & digital presence pages        |

## Official palette

| Token         | Hex                                         | Role                                       |
| ------------- | ------------------------------------------- | ------------------------------------------ |
| Aviator Blue  | `#143048`                                   | Primary brand / AVIATOR wordmark / wings   |
| Aviator Gold  | `#9E712E` → `#CCA04C` → `#F6C36C` (mid CTA) | Accent / PASS wordmark / book / highlights |
| Academic Grey | `#7C7B80`                                   | Secondary / muted UI / taglines            |

| Token     | Hex       | Role                       |

## Typography

| Role     | Brand font      | Web substitute               |
| -------- | --------------- | ---------------------------- |
| Headings | Stimulatio Flat | Exo 2 (wide / aerodynamic)   |
| Body     | IBM Plex Sans   | IBM Plex Sans (Google Fonts) |

Load licensed Stimulatio Flat under `public/fonts/` when available and set `brandingConfig.pending.officialTypography = false`.
