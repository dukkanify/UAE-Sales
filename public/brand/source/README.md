# Brand source assets

Official AviatorPass brand guidelines for audit and regeneration of digital assets.

## Files

| File                               | Purpose                                      |
| ---------------------------------- | -------------------------------------------- |
| `AVIATORPASS_Brand_Guidelines.pdf` | Official brand book (current upload)         |
| `ATPL_PASS_Brand_Guidelines.pdf`   | Prior guidelines copy (retained for history) |
| `guidelines-cover.png`             | Cover page reference                         |
| `guidelines-palette.png`           | Colour palette page                          |
| `guidelines-typography.png`        | English typography page                      |
| `guidelines-logo-page.png`         | Logo lockups page                            |

## Official palette

| Token                           | Hex       | Role                                    |
| ------------------------------- | --------- | --------------------------------------- |
| Aero Blue                       | `#2E7DAA` | Primary brand / CTAs / AVIATOR wordmark |
| Altitude Orange / Success Amber | `#DD9B30` | Accent / PASS wordmark / highlights     |
| Academic Grey                   | `#7C7B80` | Secondary / muted UI / book mark        |

## Typography

| Role     | Brand font      | Web substitute               |
| -------- | --------------- | ---------------------------- |
| Headings | Stimulatio Flat | Space Grotesk                |
| Body     | IBM Plex Sans   | IBM Plex Sans (Google Fonts) |

Load licensed Stimulatio Flat under `public/fonts/` when available and set `brandingConfig.pending.officialTypography = false`.
