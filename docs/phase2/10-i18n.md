# P2-10 — Multi-language platform

## Goal

Unlimited locale packs while v1 English remains default.

## Examples

English, Arabic (RTL), French, German, Spanish, Chinese

## Approach

- Message catalogs + RTL layout tokens
- Content translations for courses separate from UI strings
- Flag: `i18n` — when off, force `englishOnly`

- [ ] Locale switcher (when flag on)
