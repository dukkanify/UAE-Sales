# Future roadmap — ATPL PASS

Post-launch priorities (support & maintenance phase). Suggested order — not calendar estimates.

## Near term

1. Complete Supabase cutover (auth users, courses, learning, payments tables).  
2. Live Stripe Checkout + webhooks + Connect payouts in production.  
3. Live Zoom OAuth / Meeting SDK with attendance sync.  
4. Transactional email (OTP, receipts, class reminders) via production ESP.  
5. Full WCAG audit + remediation pass.  
6. Expand UAT to Playwright browser matrix (Chrome, Firefox, WebKit).

## Medium term

1. Richer blog/CMS and marketing pages.  
2. Advanced quiz question banks and proctoring options.  
3. Deeper BI exports and scheduled email reports.  
4. Mobile-optimized PWA shell.  
5. Multi-tenant school branding (white-label).

## Longer term

1. Simulator / scenario training modules.  
2. Airline partner SSO.  
3. Offline lesson packs.  
4. Marketplace for third-party ATPL content.

Track work as GitHub issues; keep critical production defects ahead of roadmap items.
