# Future roadmap — ATPL PASS

Post-launch priorities (support & maintenance phase). Suggested order — not calendar estimates.

Track live items in **Ops Center → Roadmap** (`/super-admin/ops-center`). Narrative below mirrors Task 021 Version 1.1 planning.

1. Supabase production cutover (auth, courses, learning, payments).
2. Live Stripe Checkout + webhooks + Connect payouts.
3. Live Zoom OAuth / Meeting SDK with attendance sync.
4. Native mobile applications (iOS / Android on Mobile API v1).
5. Microsoft Teams integration.
6. Google Meet integration.
7. AI proctoring.
8. Advanced exam security.
9. Multi-language support.
10. Multi-tenant architecture.
11. Advanced CRM integration.
12. Advanced marketing automation.
13. Enterprise reporting.
14. Transactional email (OTP, receipts, class reminders) via production ESP.
15. Full WCAG audit + remediation pass.
16. Expand UAT to Playwright browser matrix (Chrome, Firefox, WebKit).

## Medium term (1.2+)

1. Richer blog/CMS and marketing pages.
2. Advanced quiz question banks and deeper proctoring options.
3. Deeper BI exports and scheduled email reports.
4. Mobile-optimized PWA shell.
5. Multi-tenant school branding (white-label).

## Longer term (2.0)

1. Simulator / scenario training modules.
2. Airline partner SSO.
3. Offline lesson packs.
4. Marketplace for third-party ATPL content.

Track work as GitHub issues and Ops feature requests (`FEAT-*`); keep critical production defects ahead of roadmap items.
