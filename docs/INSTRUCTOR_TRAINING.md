# Instructor training — ATPL PASS

Suggested live session: **~60 minutes** on staging. Self-serve: `docs/INSTRUCTOR_GUIDE.md`.

## Agenda

| Block                     | Duration | Topics                                                   |
| ------------------------- | -------- | -------------------------------------------------------- |
| 1. Instructor home        | 5 min    | Dashboard, nav, profile                                  |
| 2. Courses                | 15 min   | Create/edit course, modules, lessons, resources, publish |
| 3. Live classes           | 10 min   | Schedule Zoom class, join link, attendance, recordings   |
| 4. Students               | 5 min    | Enrollments, progress visibility                         |
| 5. Quizzes                | 10 min   | Build quiz, question bank, grading                       |
| 6. Reports & certificates | 5 min    | Progress reports, issued certificates                    |
| 7. Wallet & AI assist     | 5 min    | Earnings overview, write assist (if enabled)             |
| 8. Communication          | 5 min    | Announcements, community, support                        |

## Hands-on exercises

1. Create a draft course with one module and one lesson; upload a resource.
2. Schedule a live class for tomorrow; open join preview.
3. Create a short quiz linked to the course; preview as student (second account).
4. Open instructor reports and export if available.
5. Post a community or announcement update.

## Must know

- Instructors manage **own** courses (`COURSES_OWN`).
- Demo OTP is for non-production only.
- Do not share Zoom host credentials in lesson text.
- Support tickets escalate via in-app support or admin.
