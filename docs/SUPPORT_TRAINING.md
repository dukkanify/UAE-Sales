# Support team training — AviatorPass

Suggested live session: **~45 minutes**. References: `docs/SUPPORT.md`, `docs/OPS_SUPPORT.md`, `docs/POST_LAUNCH_SUPPORT.md`, Ops Center Knowledge tab.

## Agenda

| Block              | Duration | Topics                                           |
| ------------------ | -------- | ------------------------------------------------ |
| 1. Channels        | 5 min    | In-app tickets, email, admin reports, Ops Center |
| 2. Triage & SLA    | 10 min   | Critical/High/Medium/Low; configurable SLA       |
| 3. Ticket workflow | 10 min   | New → ack → in progress → resolved → closed      |
| 4. Incidents       | 5 min    | Incident register, severity, postmortem fields   |
| 5. Escalation      | 5 min    | When to page Super Admin / vendor                |
| 6. Knowledge base  | 5 min    | Search FAQs / troubleshooting articles           |
| 7. Hypercare       | 5 min    | Check-ins during launch window                   |

## Escalation matrix

| Situation            | First line              | Escalate to                |
| -------------------- | ----------------------- | -------------------------- |
| Password / OTP help  | Support                 | Admin (ESP settings)       |
| Course content issue | Support → Instructor    | Admin                      |
| Payment failure      | Support                 | Super Admin / Stripe owner |
| Outage / 5xx         | Support                 | Super Admin + vendor       |
| Suspected breach     | Super Admin immediately | Vendor + client security   |

## Hands-on exercises

1. Create a support request in Ops Center; acknowledge; resolve.
2. File a low-priority bug; move through statuses.
3. Open Knowledge → find OTP FAQ; link in reply notes.
4. Review open alerts on Health tab; practice Ack / Resolve.
5. Read SLA policy; confirm Critical ≤ 2h response.
